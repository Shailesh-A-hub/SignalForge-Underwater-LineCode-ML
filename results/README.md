# SignalForge Results Directory

Simulation and experiment outputs are saved here as `.mat` files.

| File | Contents |
|---|---|
| `exp1_ber_vs_snr.mat` | BER vs SNR sweep (Exp 1) |
| `exp2_ber_vs_multipath.mat` | BER vs multipath severity (Exp 2) |
| `exp3_ber_vs_doppler.mat` | BER vs Doppler velocity (Exp 3) |
| `exp456_properties.mat` | Bandwidth, DC, sync comparison (Exp 4–6) |
| `exp7_adaptive.mat` | Adaptive selection scenarios (Exp 7) |
| `run_YYYYMMDD_HHMMSS.mat` | Manual saves from GUI |
